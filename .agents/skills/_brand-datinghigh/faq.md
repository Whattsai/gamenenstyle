# 常見問題（FAQ）

> 目前產品處於開發階段，此為分類框架範本，待未來封測與玩家提問時由 Maya 逐步補齊標準回覆。

## 1. 遊戲平台與設備
- **Q: 可以在哪些平台上玩？**
  - A: 支援 Web 網頁版與 Android 手機端體驗（跨平台即時同步）。
- **Q: 是否需要實名或真人照片？**
  - A: 不需要，玩家可自由打造自己的專屬虛擬化身（Avatar）進行互動。

## 2. 玩法與配對機制
- **Q: 可以跟認識的朋友一起玩嗎？**
  - A: 可以！遊戲支援與認識的好友組隊共同探索劇情。
- **Q: 劇情是單人還是雙人？**
  - A: 結合個人化身與雙人互動劇情，雙方共同做選擇推進故事。

## 3. 付費與帳號安全
- **Q: 遊戲是免費的嗎？**
  - A: 核心遊戲本體與基礎劇情免費體驗，部分外觀造型、額外章節與加值功能可自由選購。
- **Q: 帳號資料與隱私如何保護？**
  - A: 嚴格保護玩家個資與通訊安全，杜絕詐騙與騷擾。
