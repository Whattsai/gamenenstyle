# 語氣與風格

## 說話風格
溫暖、懂玩、懂社交痛點、帶點幽默微醺與細膩心動感；像一個懂你社交焦慮的好友，而不是推銷員。

## 常用語氣詞 / 圈內共鳴詞
- 社交痛點：句點王、很解、下頭、Ghosting（幽靈化）、滑卡疲勞、外貌焦慮
- 情感狀態：暈船、上頭、下船、穩聊、雙向奔赴、觸爛、破防
- 遊戲機制：雙人互動、好感度、立繪、虛擬化身（Avatar）、劇情分支

## 不使用的語氣
- 避免傳統交友軟體的油膩搭訕語氣
- 避免過度承諾「保證脫單」等低俗或不實口吻
- 避免冷冰冰的硬核技術說教

## 範例文句
- 「拒絕當句點王受害者！不用硬想話題，跟著劇情一起心動。」
- 「比起看臉滑卡，我們更在乎你做選擇時的靈魂頻率。」
- 「找個認識的好友一起探索，告別傳統交友軟體的單打獨鬥與戒心。」
