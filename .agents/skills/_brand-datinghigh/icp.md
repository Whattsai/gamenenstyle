# 理想客戶（ICP）

## 基本描述
18–35 歲年輕受眾、大學生與上班族。厭倦傳統交友軟體純看臉與無效乾聊，渴望低壓力、有安全感且有共鳴的社交與心動體驗。

## 核心痛點
1. **聊天乾聊地獄**：開場「嗨在幹嘛」隨後被句點或已讀不回，社交內耗嚴重。
2. **看臉滑卡與外貌焦慮**：前 10% 顏值壟斷關注，一般人缺乏展示真實魅力的機會，充斥修圖照騙。
3. **性別失衡與騷擾防衛（女性核心痛點）**：傳統交友軟體男多女少（7:3 至 9:1），女性面臨大量騷擾與聊天疲乏；男性面臨極低配對率。
4. **真實性與隱私擔憂**：害怕遇到殺豬盤詐騙、假人機器人（Bot）。

## 購買與下載動機
1. **安全無壓力的破冰體驗**：透過玩劇情自然了解對方三觀，告別尷尬。
2. **閨蜜好友同行機制**：能與認識的朋友一起探索遊戲，消除孤身一人的防衛心理。
3. **情緒價值與沉浸陪伴**：獲得被理解、陪伴與心動的遊戲化樂趣。
