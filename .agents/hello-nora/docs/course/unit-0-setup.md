# Unit 0｜環境建置 + 品牌資料建置

> 這個單元完成後，AI 可讀取你的專案品牌資料，並確認目前環境支援的安全設定。

## 前置能力

需要 Python 3.10 以上、專案檔案讀寫與命令執行能力。安裝不依賴 Git；來源更新才需要 Git。
搜尋、圖像生成、MCP、平台連線及持續排程依實際環境啟用。沒有對應工具時，先使用內容草稿與手動發布流程。

## 🎙️ 推薦工具：Typeless

> 裝了這個，整個課程從「打指令」變成「跟 AI 說話」。

你不需要一直打字。Typeless 是一個語音輸入工具——你說話，它幫你把話轉成精準的文字，直接貼進 AI 工作環境。

不管是跟 Nora 說「幫我排這週的貼文」，還是叫 Leon「做一個 Landing Page」，**開口說就好，不用打字**。

### 下載

前往 **[typeless.com/downloads](https://www.typeless.com/downloads)**，選你的平台下載（Mac / Windows / iOS / Android 都支援）。

### 使用方式

1. 安裝後，點選啟動按鈕（或設定快捷鍵）
2. 對著麥克風說話
3. Typeless 自動把語音轉成文字，輸出到你目前使用的視窗
4. 回到 AI 工作環境，你說的話就出現在輸入框裡——按 Enter 送出即可

> 💡 Typeless 會自動過濾「呃」「那個」這類口頭語，讓轉出來的文字乾淨清楚。
>
> ⚠️ **重要：記得把語言變體改成「繁體中文」**——預設可能是簡體中文，轉出來的字會不對。設定路徑：Typeless 偏好設定 → 語言 → 變體 → 選「繁體中文（台灣）」。

## Step 1–3：確認環境並安裝整個團隊

依 [INSTALL.md](<../INSTALL.md>) 的統一入口，指定既有目標專案：

```text
python "<工具位置>/scripts/install.py" --project-root "<目標專案>"
python "<工具位置>/scripts/install.py" --project-root "<目標專案>" --install
```

第一個命令只預覽，第二個執行。五位角色、10 個輔助技能、工作流、腳本與字型會完整複製到專案。
重新載入技能或開新對話，確認目前環境能讀到專案 `.agents/skills/`，再進行品牌建置。

## Step 4：建立你的品牌資料

✏️ 輸入：

```
/brand-setup
```

AI 會開始用中文問你幾個關於品牌的問題，一次一個，大概 10 分鐘可以完成。

如果你有官網或社群頁面，把網址貼給它——AI 可以直接讀取，幫你自動整理品牌資訊。

> 💡 兩種方式擇一即可：**對話式**（上面的 `/brand-setup`，最輕鬆，約 10 分鐘）；或**自己填**（打開 `_brand/` 4 個檔逐一填，步驟見 [BRAND-SETUP.md](<../BRAND-SETUP.md>)）。不用兩個都做。

---

## Step 5：驗收品牌資料

問答結束後，✏️ 輸入：

```
/brand-check
```

AI 會列出剛才建立的 4 份核心品牌檔案（外加選填的產業知識、FAQ）、摘要每份內容，讓你確認沒有缺漏。

> 看到 ⚠️ 標記就代表那邊還沒填好，AI 會告訴你怎麼補。

---

## Step 6：開啟安全防護

輸入 `/safety-setup`。它會先確認執行環境支援的設定方式，再處理危險刪除、Git 強制覆蓋與系統操作防護。
支援時先給出具體規則與設定位置，經同意後套用；不支援就清楚說明，不能宣稱防護已生效。
白名單／自動允許為選用：A. 唯讀；B. 指定品牌／草稿編輯及已確認的工具；C. 自訂。依環境實際可限制的範圍設定。
工具允許設定不會取代 `_brand/account-safety.md` 的發布前確認、廣告金額確認與節流。

## ✅ 驗收任務

- [ ] 五位角色與 10 個輔助技能、工作流、腳本、字型均齊全。
- [ ] `/brand-check` 檢查 4 份核心品牌資料；產業知識與 FAQ 可持續補充。
- [ ] `/safety-setup` 清楚列出已套用、未支援與待驗證的防護；不把檢查清單當成技術封鎖。

## 小提示

品牌資料是團隊的共用大腦，填得越清楚，產出越貼近你的品牌風格。先讓團隊認識你，再逐步串接平台。
