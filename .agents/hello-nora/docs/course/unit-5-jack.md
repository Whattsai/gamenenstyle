## 你會得到什麼

Jack 用三層漏斗思維管理你的 Meta 廣告：
- **冷受眾（40%預算）**：陌生人，用勾人的 hook 先讓他認識你
- **暖受眾（50%預算）**：看過你內容的人，推深一點的訊息
- **熱受眾（10%預算）**：快要轉換的人，直接給他最強的理由

他有 **5 個技能點**，這個單元會帶你一個一個用過、每個都當場驗收：

- **5-1　廣告文案 / Hook**：5 種公式（痛點／好處／社證／敘事／爭議），並建議先測哪個
- **5-2　影片廣告腳本**：15 秒腳本，照五大架構寫
- **5-3　受眾 + 預算規劃**：用三層漏斗幫你分配預算、規劃廣告組合
- **5-4　廣告數據週報**：給加碼／暫停／換素材建議（數字貼給他就行；想自動拉 Meta 數據需先串接，門檻見 5-4）
- **5-5　兩階段投放**：沒投過也行——先了解你現況，再帶你規劃

> 想看 Jack 完整能耐？裝好後直接問他「**你會做什麼**」。

## Jack 的 5 個技能點（跟著做，一項一驗收）

> 有在跑廣告先做 **5-4（數據週報）**；還沒跑就從 **5-1（Hook）** 或 **5-5（兩階段投放）** 開始。每一項都有明確的「✅ 驗收」。指令透過 Nora 轉給 Jack，想直接找他打 `/jack-ads`。

### 5-1　廣告文案 / Hook

✏️ 複製貼給 AI：

```
/hello-nora 請 Jack 幫我寫 5 個廣告 hook，產品是 [你的產品]
```

Jack 用 5 種公式（痛點／好處／社證／敘事／爭議）給你 hook，並建議先測哪一個。

> ✅ **驗收**：你有 5 個不同角度的廣告 hook，知道先測哪個。

### 5-2　影片廣告腳本

✏️ 複製貼給 AI：

```
/hello-nora 請 Jack 幫我寫一支 15 秒廣告腳本，產品是 [你的產品]
```

照五大架構（鉤子 → 痛點 → 方案 → 證明 → 行動）寫成可直接拍的腳本。

> ✅ **驗收**：你有一支 15 秒、分鏡清楚的廣告腳本。

### 5-3　受眾 + 預算規劃

✏️ 複製貼給 AI：

```
/hello-nora 我有每天 [XX 元] 預算，請 Jack 幫我分配
```

Jack 用三層漏斗（冷 40%／暖 50%／熱 10%）幫你分配預算、建議開幾組廣告組合。

> ✅ **驗收**：你有一份「預算怎麼分、開幾組」的具體規劃。

### 5-4　廣告數據週報

✏️ 把廣告數據截圖或貼上數字：

```
/hello-nora 請 Jack 看這組數據，告訴我該怎麼做
[貼上你的數據]
```

Jack 幫你讀 CTR／CPM／ROAS，給你加碼／暫停／換素材的具體建議。**最簡單：把後台數據截圖或數字貼給他就行，不用串接任何東西。**

> 💡 **想讓他「自動拉數據」、不想每次手動貼？** 那要先串 Meta Ads MCP，門檻先講清楚（照 `/setup` 一步步帶你接）：
> - 需要 **可使用 MCP 的執行環境**，而且你是該 Meta 企業管理（Business Manager）的**管理員**。
> - 用的是 **Meta 官方免費連接器**（不用開發者權杖）；但官方正分批開放，**台灣帳號可能還沒輪到**——接了卻顯示「未啟用」不是你做錯，是還沒開放到你。
> - 還沒開放時可先用備案 **pipeboard**（第三方、能立刻用），但**免費方案每週只有 30 次查詢**，狂用要付費，先知道別撞牆。
> - 沒串也完全不影響——把數字貼給 Jack，他一樣幫你分析。
> - 👉 **想自己接？完整手動步驟見本單元最後〈進階：串接 Meta Ads MCP〉。**

> ✅ **驗收**：你知道這組廣告該加碼、暫停、還是換素材。

### 5-5　兩階段投放（沒投過也能上手）

✏️ 複製貼給 AI：

```
/hello-nora 我沒投過廣告，請 Jack 帶我規劃 [產品] 的第一波投放
```

Jack 先了解你的現況，再一步步帶你把第一波廣告規劃出來。

> ✅ **驗收**：你有一份新手版的第一波投放計畫，知道下一步做什麼。

## 進階：串接 Meta Ads MCP（讓 Jack 自動拉數據，不用每次手動貼）

> 這是 5-4 的延伸。接好之後，Jack 不用你每次手動貼數字——他自己連到你的 Meta 廣告帳號讀成效。

> 💡 **這個官方連接器其實「讀」跟「寫」都能做**：除了讀數據，它也能用自然語言建立、修改廣告活動。但**它不會自動把廣告投出去**——Jack 只會「提議」改動，要你親自確認、按下去才算數，而且新建的活動預設是「**暫停**」狀態。**這個單元我們聚焦在用它「讀數據、做分析」**；下廣告、改預算這種動到錢的事，建議還是你自己在 Meta 後台決定，最安全。

> ⚠️ **前置需求**：可使用 MCP 的執行環境＋你是該 Meta 企業管理（Business Manager）的管理員。官方連接器本身免費（只付你原本的 執行環境費用）。

**⚠️ 先講台灣的現實（很重要）**：官方免費連接器正全球分批開放，優先美國與高消費帳戶，**台灣帳號可能還沒輪到**。如果你照下面接了卻顯示「未啟用 / not enabled」，**不是你做錯，是 Meta 還沒開放到你的帳號**——這時用下面的 pipeboard 備案，或過陣子再試官方。

### 步驟 1（首選）：接 Meta 官方免費連接器

1. 先查核目前環境的 MCP 設定文件，使用其支援的 HTTP 連接器介面或設定檔
2. 名稱填 `Meta Ads MCP`，網址貼 `https://mcp.facebook.com/ads` → 按「連接」
3. 跳出 Meta 授權頁 → 用 **Facebook 登入** → 選「**僅此商家 / Opt in for current business only**」→ 選你的企業管理帳戶 → 核准權限
4. 接好後**依環境方式重新載入連線**

> 📎 網址以 Meta 官方為準：這條 `mcp.facebook.com/ads` 是 Meta 官方公告的進入點，登入後由 Meta 的 OAuth 認證你的帳號。若 Meta 的設定頁給你一條不一樣的專屬網址，**以 Meta 頁面給的那條為準**。

> 🧭 **找不到上面的選單名稱？** 執行環境的設定介面可能不同，按鈕文字或位置可能跟這裡不完全一樣。找不到就把畫面截圖貼給 Jack，我帶你一步步點。

### 步驟 2（備案）：官方還沒開放到你時，用 pipeboard

> ⚠️ pipeboard 是第三方服務、而且**會用到付費額度**：免費方案**每週只有 30 次查詢**，超過要付費。所以只當「官方還沒開放」時臨時頂著——**官方一旦開放就換回官方**（免費、沒有查詢上限）。

1. 到 **[pipeboard.co](https://pipeboard.co)** 用 **Facebook 登入**授權
2. 拿到一組連接器網址：`https://meta-ads.mcp.pipeboard.co/?token=你的TOKEN`
3. 照**步驟 1 的同樣方式**把這組網址加入環境的 MCP 設定，一樣依環境方式重新載入連線

### 步驟 3：驗證 + 實戰

✏️ 在 AI 工作環境 輸入：

```
/jack-ads 列出我的廣告帳號
```

看到廣告帳號清單就接通了；顯示空的、或標示「未啟用」多半是官方還沒開放到你，回**步驟 2** 用備案。

接通後就能讓 Jack 直接拉數據：

```
/jack-ads 幫我拉最近 7 天廣告成效，告訴我哪一組該加碼、哪一組該停
```

> 💡 **接不上不用焦慮**：台灣現在十之八九是「還沒輪到官方開放」，不是你設定錯。先用 pipeboard 頂著，或乾脆把數字貼給 Jack，照樣能跑，等官方開放再換回來。
