# 常見問題 Q&A

## 安裝與能力

### Q：需要特定模型或訂閱嗎？

以實際能力判斷：安裝需要 Python 3.10 以上、檔案讀寫與命令執行；技能使用需要讀取專案檔案。
搜尋、生圖、MCP、API 與排程則依實際工具與帳戶權限。沒有連線就使用手動發布或貼數據分析，不要求某個模型或付費方案。

### Q：我完全不會寫程式，學得會嗎？

可以。業務工作直接跟 Nora 說需求；安裝時請 AI 依 [INSTALL.md](<INSTALL.md>) 的統一入口先預覽，再執行。請先指明目標專案。

### Q：Mac、Windows 或沒有 Git 的專案能用嗎？

安裝器只用 Python 標準函式庫，支援有 Git／無 Git 及中文、空白路徑。各業務工作流另有依賴，例如影片字幕仍保留原有 macOS 實測限制。

### Q：手機或另一台電腦會自動同步嗎？

這份工具安裝在指定專案，不宣稱跨裝置同步。使用環境必須能讀取該專案。搬移品牌資料時請保護 `_brand*` 內的憑證與稱呼，不要放進公開或共用雲端。

### Q：可以同時管理多個品牌嗎？

可以。跟 Nora 說「新增品牌」，另建 `_brand-品牌名/` 並逐題訪談。每次選定品牌後，brief 明列品牌路徑，不混用資料。

### Q：找不到 `/hello-nora` 指令？

先確認目前專案 `.agents/skills/hello-nora/SKILL.md` 存在，再確認環境是否支援技能探索與斜線指令。
可以直接請 AI 讀取該檔案並使用技能。依環境方式重新載入或開新對話；缺檔時用原安裝器預覽修復。

### Q：同名技能衝突或管理檔案有本地修改？

安裝器會停止，保留現況。先檢查並備份、合併差異，不強制覆蓋，也不把非管理技能自動收編。

### Q：怎麼更新與移除？

更新先執行工具內來源更新技能的暫存三方比較，驗證後回報；明確同意同步專案後才執行安裝器。
移除使用同一入口的 `--remove` 預覽，加 `--install` 才執行。品牌、憑證、稱呼、備份、其他技能保留。命令見 [INSTALL.md](<INSTALL.md>)。

## 卡關自救

把錯誤訊息、使用的環境、目前專案與已做步驟提供給 AI 診斷；不要貼出 Token 或密碼。
暫時無回應時可開新對話、分段提供資料、檢查網路與當期用量，或重新載入環境。

## ⚙️ 自動化與平台串接

### Q：我照做了，為什麼 Meta 廣告數據還是拉不到？

這不是你做錯。Meta 官方那個「自動拉廣告數據」的免費工具是**全球分批開放**的，台灣的廣告帳號很多還沒輪到，沒輪到就是接不上——這是 Meta 那邊的進度，急不來。在那之前完全不影響你用 Jack：把後台數據**貼給他**，他一樣幫你分析該加碼、暫停還是換素材，結果一樣，只是少了「自動」那一步。

### Q：Google 日曆串接看起來好難，一定要弄嗎？

不一定，這是全課**最進階、可以直接跳過**的一段。沒串接也不影響——Nora 一樣會幫你把這週該做的事列成清單，你自己貼進日曆就好。等哪天真的覺得手動貼有點煩，再回去照教學串也不遲。

### Q：我沒有 WordPress，Iris 還能幫我自動發文章嗎？

自動發文那段是給有 WordPress 的人用的。如果你用的是 Kajabi、Teachify、Wix 這類平台（多數台灣賣課的人都是），Iris 一樣幫你把整篇文章寫好，你**複製貼上、發布**，大概 2～3 分鐘。內容品質完全一樣，只是最後一步手動。

### Q：Nora 不是會自動追進度、提醒我嗎？為什麼都要我先開口？

對，預設是「**你開口，她才動**」——你問「進度怎麼樣」她就盤點給你。真正「每天早上自動跳出來提醒、推到手機」那種，要額外接排程工具＋可持續執行的環境才做得到，不是裝好就會自己跑。最省力的用法：養成每天開個對話跟 Nora 說一句「今天有什麼要盯的」，效果一樣。

### Q：為什麼裝好了還不能自動發文、自動拉數據？

團隊的「**腦**」（想策略、寫文案、做規劃）裝好就完整能用；但「**手腳**」（自動發文、自動拉數據）屬於進階，需要對應工具與平台權限＋你自己去接一下平台，部分還要看平台對台灣開放沒。先用「腦」把內容做出來、手動發，流程跑順了再接自動化也不遲。

### Q：跨對話怎麼記得品牌？

有檔案讀取能力時，下次從相同專案讀取選定的 `_brand*`。不能讀檔時，先請 Nora 整理品牌摘要，再貼到新對話。

### Q：品牌資料一定要填嗎？

強烈建議填。五位夥伴是靠你填的品牌資料（語氣、產品、理想客戶）來「懂你」的——填得越完整，產出越貼近你的風格，越不用每次重講。可以先裝好、先試玩，品牌資料之後慢慢補。怎麼填見 [BRAND-SETUP.md](<BRAND-SETUP.md>)。
