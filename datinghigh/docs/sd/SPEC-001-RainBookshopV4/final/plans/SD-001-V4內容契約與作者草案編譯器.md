## 功能概述

負責將唯一權威作者原稿 `docs/requirements/rain-bookshop-v4-draft.json`（SHA `b5c18f67...`，2,245 行）無損編譯為 `scene-event.v3` 四層不可變內容包 `contracts/rain-bookshop-v4.json`，完成 16 本公有領域經典使用地法域權利核實與 62 項新素材（45 圖＋17 音）建置、18 項 V3 素材沿用校驗（零重複副本），擴充 Worker 與發布工具支援 `scene-event.v2`/`v3` 雙版本讀取、可配置倒數門檻、雙題組四取書位置與 `<= 50,000` 商狀態可達圖驗證，並完成隔離候選發布驗證（保持 `contracts/scene-event-content.json` default local 首場索引至 `SD-006` Gate A 驗證同一 SHA 時切換）。排除任何業務狀態 I/O、資料庫 schema 變更與前端畫面實作。

## 用戶故事

本包為離線內容建置、型別驗證與 R2/D1 發布工具層，無直接玩家前端畫面（42 個 `@frontend` 場景畫面由 `SD-004` 與 `SD-005` 實作，本包提供其全部正式圖片、音訊、座標、`hitShape` 與 `uiCopy` 資料源）：
1. 前置關卡：確認 `SD-003-S01` 真 Miniflare D1 毫秒時鐘與同批回滾探針已通過。
2. 權利與素材關卡（`S01`）：核實 16 本經典與 62 項新素材權利並寫入 `contracts/rain-bookshop-v4-rights.json`，建置 45 張 PNG/WebP 與 17 個 WAV 至 `contracts/story-assets/`，核驗 18 項沿用資產 SHA 與尺寸。
3. 契約與編譯關卡（`S02`～`S04`）：擴充 `scene-event.v3` Zod schema（含可配置 `durationSeconds` 與雙題組四位置），執行 `compileRainBookshopV4FromDraft` 產出 `contracts/rain-bookshop-v4.json` 並逐 Unicode scalar 反查原稿零差異。

### 契約、資料與平台

- **契約與版本**：嚴格對齊 [01-system-design.md](../01-system-design.md#契約與資料設計) 定義之 `CNT-001`（`scene-event.v3`）、`CNT-002`（動作白名單＋書籤 `0..20` Unicode scalar）、`CNT-003`（actor-scoped 快照＋單人 `own_profile` 興趣）與 `CNT-004`（私有 `story.framework.system.reconcile`）。
- **資料庫與儲存限制**：維持 `0001`～`0007` **21 張表、0 新欄、0 SQL Trigger、0 新增公開 HTTP 路由**；維持 `world_state_json <= 16,384`、`state_json <= 16,384`、manifest `<= 512KiB`／`4MiB`、素材 `<= 8MiB`、可達狀態 `<= 50,000`。
