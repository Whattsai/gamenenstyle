### F-01：`cloudflare/src/scene-event-track-content.ts`
trackScene/Narrative/Pool/Definition schema、validateTrackContent：v4 受控版本分支與 strict 字段、content scalar 對照、兩題組、90/120 設定與 threshold；保留 v2 原驗證。

### F-02：`cloudflare/src/scene-event-track-graph.ts`
validateTrackReachability：v4 typed state canonical signature，重複 ambient 不展開無限歷史；遍歷 28 節點、4 ending、兩題組；50000 上限不放寬。

### F-03：`cloudflare/src/scene-event-content.ts`

### F-04：`cloudflare/src/scene-event-stage-content.ts`

### F-05：`tools/scene-event-content-policy.mjs`

### F-06：`tools/scene-event-publish-policy.mjs`
validateFormalSceneEventBundles / publishSceneEventBundles：嚴格核對正式素材 bytes/SHA/容量、權利及圖可達性；版本化 publication，舊場仍 pinned；Gate B 後才依明確清單移除 V3 索引。

### F-07：`tools/rain-bookshop-v3-policy.mjs`
validateFirstStoryAuthoring / validateRainBookshopV3：維持 V3 原檢查，新增明確版本分派；不以 V4 規格重驗既有 V3 內容。

### F-08：`contracts/scene-event-content.json`
正式索引依版本化 bundle/manifest；V3 舊 SHA 保留至 Gate B，後續只移除具名批准版本。
