## 功能概述

本分項負責將 `SD-002` 的純領域規則接通至 `.NET 10` `Application`／`Api` 與 Cloudflare Worker／D1／R2／`GameRoomSocket` Durable Object，在不新增任何資料庫欄位、SQL Trigger 或公開 HTTP 路由的前提下，實現：
1. 多步有限模組狀態與雙軌協調的單一 D1 batch CAS 原子提交；
2. 真 D1 SQL 時間 guard（`now < deadlineAt`）與最後 1 毫秒救書／超時結算／玩家退出跨 Worker 競態線性化；
3. 固定私有命令 `story.framework.system.reconcile` 與 `operationIdentity`＋CAS 系統 `NULL` actor 事件唯一去重（不依賴 SQLite `NULL UNIQUE`）；
4. `GameRoomSocket` DO 跨多分頁與權杖刷新的 role 有效連線／前景狀態聚合，以及 `min(nonceExpiry, idleDueAt, deadlineAt)` 最早到期排程與 `GET /experience` 懶補償兜底；
5. HTTP 與 WebSocket 雙 transport 完全一致的嚴格授權、receipt 冪等，以及未撕盲書、未揭曉答案、未授權書籤 `note`、他人私密興趣與私人化身資產的全路徑隔離。

- **明確排除**：本包不改前端 UI 元件（歸 `SD-004`、`SD-005`），不改離線編譯器（歸 `SD-001`），不執行 Local 舊資料刪除（歸 `SD-007`）。

## 畫面操作／系統處理流程

詳見 [01-system-design.md 架構與資料流序列圖](../01-system-design.md#架構與資料流)：
1. `GET /api/v1/game-rounds/{id}/experience`：驗權 → 若當前 `sv4-rescue-coop` 為 `running` 且已越過 `earliestPauseDueAt` 或 `deadlineAt`，先呼叫內部懶補償 `reconcileIfNeeded` → 查詢同 Round 已完成同版 V4 結局集合（僅 `completed` 階段需要）→ 呼叫 `SceneEventFrameworkService.ProjectAsync` 組裝本人白名單 DTO（`Cache-Control: no-store`）。
2. `POST /api/v1/game-rounds/{id}/story/event` 與 WS `story.event.submit`：共用同一套授權、receipt 重播檢查、`SceneEventFrameworkService.CommandAsync` 評估與 `executeV4TrackBatch` D1 原子提交 → 提交成功後通知 `GameRoomSocket` 更新排程並廣播安全 `room.snapshot_hint`。
3. `GameRoomSocket` 連線與 `alarm()`：管理單次票券兌換、聚合各 role 有效連線與前景狀態、維護最早到期 `setAlarm`，到期時經內部私有橋接呼叫 `story.framework.system.reconcile`。

### 契約、資料與平台

- **關鍵技術防護（D1 Batch 條件一致性）**：在 SQLite / Cloudflare D1 中，`db.batch([stmt1, stmt2, ...])` 只有在語句拋出 SQL 錯誤（如 constraint failure）時才會回滾前序語句，單純 `UPDATE ... WHERE ...` 影響 `0 rows` 不會自動取消後續語句！因此本設計強制規定：同批次內所有 `UPDATE` 與 `INSERT` 語句的 `WHERE` 子句皆共同綁定相同的權威前置條件（`round.status = 'active'`、`session.shared_revision = ?expectedSharedRev`、目標 instance `revision = ?expectedInstRev` 及救書 `now < deadlineAt`），並在最後附帶一條驗證斷言查詢，確保在任何跨 Worker 競態下**要麼全部語句同時命中生效，要麼全部語句 `0 rows` 零部分寫入**！這項設計將在 `SD-003-S01` 以真 Miniflare D1 跨提交競態直接驗證。

### 共用與改動合理性

- 零新增公開端點，完全復用既有 `/experience`、`/story/event`、`/chat/messages`、`/story/next`、`/end` 與 `/ws/game-rounds/{id}` 授權中介層；私有 `story.framework.system.reconcile` 僅註冊於 `Program.cs` 內部橋接 switch，對外不可見。
