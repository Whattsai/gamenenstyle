# Orick 項目開發規範

這是 Orick 項目的 AI 開發規範，所有 AI 助手必須遵循這些規則。

---

## 語言規範

1. **所有回覆使用繁體中文**
2. **代碼註釋使用繁體中文**：
   - C# XML 文檔註釋（`///`, `<summary>`）
   - 行註釋（`//`）
   - 塊註釋（`/* */`）
   - TypeScript JSDoc 註釋（`/** */`）
   - Git 提交訊息
3. **所有產生的文檔、Artifacts (包含 `implementation_plan.md`, `task.md` 等) 一律使用繁體中文**
4. **所有思考過程 (thinking process) 與回應一律使用繁體中文**
5. **每一步思考都嚴格以最高深度的推論完成後，才進行行動**

## 文件管理規範

⚠️ **禁止隨意創建 Markdown 檔案**

| ❌ 禁止創建 | ✅ 正確做法 |
|-----------|----------|
| 進度報告 MD 檔案 | 更新現有文檔 |
| 配置備份檔案 | 使用 Git |
| 重複的說明文件 | 更新既有檔案 |

## 重要文檔

- `.agent/workflows/` - Antigravity 工作流程
- `AGENTS.md` - AI 指導通則
