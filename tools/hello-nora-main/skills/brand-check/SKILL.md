# 品牌資料驗收

## 我的任務

讓用戶快速確認他的品牌資料是否齊全、內容是否正確。Unit 0 結束時用這個 skill 驗收。

---

## 執行流程

### Step 1：檢查品牌檔案是否存在

依序檢查以下 4 份**核心**檔案：

```
.agents/skills/_brand/brand-guide.md
.agents/skills/_brand/voice-profile.md
.agents/skills/_brand/product-info.md
.agents/skills/_brand/icp.md
```

**另外檢查 2 份「選填但很有價值」的：**

```
.agents/skills/_brand/industry-knowledge.md   ← 產業知識（決定文案講什麼）
.agents/skills/_brand/faq.md                  ← 常見問題（給 Maya 回留言用）
```

> ⚠️ 這 2 份**沒填不算「缺檔」、不影響驗收**，有填就一起顯示。但如果 `industry-knowledge.md`
> 是空的，要在報告最後加一句提醒（不是警告）：
>
> 「💡 產業知識庫還是空的。這份決定文案「講什麼」（不是「怎麼講」），
> 填了之後 Maya 寫的東西會從『安全但空泛』變成『有觀點、內行』。
> 要我現在幫你補嗎？你講重點、或我直接幫你查一輪都可以。」

### 🗂️ 多品牌時的檢查

先看有沒有多個 `_brand-XXX/` 資料夾：
- 只有 `_brand/` → 照上面正常檢查
- 有多個 → **先問「要檢查哪個品牌？」**，或直接列出每個品牌的完整度總覽：

```
【品牌資料總覽】
✅ 客戶A（_brand-客戶A/）：4/4 核心齊全｜產業知識 ✅
⚠️ 客戶B（_brand-客戶B/）：3/4（缺 icp.md）｜產業知識 ❌ 空的
```

### Step 2：顯示驗收報告

用以下格式呈現：

```
📋 品牌資料驗收報告

✅ brand-guide.md（品牌規範）
- 品牌名稱：[從檔案讀出]
- 品牌主色：[從檔案讀出]
- 官網：[從檔案讀出]

✅ voice-profile.md（語氣風格）
- 說話風格：[摘要 2-3 個重點]

✅ product-info.md（產品清單）
- 共 [數量] 個產品/服務
- 主力產品：[列出 product-info 的主力產品；**第 1 個視為主推**]

✅ icp.md（理想客戶）
- 核心客群：[一句話摘要]

────────────────

整體狀態：[完整 / 部分缺漏]
```

### Step 3：標記缺漏

如果有檔案不存在、欄位空白、或還寫著「待補」「[填寫]」：

- 用 ⚠️ 標記出來
- 告訴用戶哪些需要補
- 建議：「跑一次 `/brand-setup` 重新建立，或自己打開檔案編輯：`open .agents/skills/_brand/[檔名]`」

### Step 4：給出下一步——能直接補的就直接接著問，不要只是「建議」

如果一切完整：

「品牌資料齊全了 ✅
你可以放心進入 Unit 1，把 Nora 拉進來。」

**如果 4 份全是空白範本（剛裝好的新學員）：不要停下來問「要不要我幫你啟動 /brand-setup」，直接開口問第一題。**
讀 `.agents/skills/brand-setup/SKILL.md`，照它的提問流程從第一題開始帶（嚴格一次只問一題）。承接語例：

> 「你的 4 份資料都還是空白，我直接帶你建，一題一題來，5 分鐘就好 👉
> 第一題：你的品牌叫什麼名字？」

**如果只是部分缺漏：** 直接把缺的那幾項當場問出來補齊，問完寫回對應檔案——不要請他自己去開檔案編輯或另跑指令。例：

> 「缺的是品牌主色跟語氣範例這兩項，我直接補問你 👉
> 1. 你的品牌主色是什麼？」

---

## 行為規則

1. **檢查階段只讀取和顯示，不憑空改檔案**——但偵測到空白/缺漏時（見 Step 4），可以直接接著訪談、把學員當場給的答案寫回對應檔案。檢查與補填是同一條龍，不要把學員推去別的指令。
2. 摘要要短——每個檔案 3-5 行重點就好，不要把完整內容貼出來
3. 用 emoji 讓報告好讀（✅ ⚠️ 📋）
4. 結尾不要停在「建議你去跑某指令」——能當場補的就直接開口問，把缺口補完
